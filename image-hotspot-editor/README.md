# 🎯 Image Hotspot Editor

可视化图片热区编辑器，支持多张图片、拖拽热区、四角缩放、一键导出独立 HTML 成品页。

> 纯前端工具，无需后端，打开即用。
>
> 属于 [tinybox](https://github.com/windfish/tinybox) 集合中的一个小工具。

## 🌐 在线体验

**[点击在线体验 →](https://windfish.github.io/tinybox/image-hotspot-editor/)**

## ✨ 功能特性

- **多图管理**：支持添加多张图片，标签页切换，每张图独立热区
- **可视化编辑**：拖拽移动热区、四角控制点缩放、边界自动约束
- **热区配置**：链接地址设置、批量添加删除、最多 10 个热区
- **一键导出**：生成单文件 HTML，双击打开即用，零依赖
  - 图片模式：外链 / Base64 内嵌（完全离线）
  - 热区样式：隐藏边框 / 显示虚线边框
  - 布局方式：垂直排列 / 水平排列
- **数据导入导出**：JSON 格式，保存草稿方便复用
- **响应式成品**：导出的 HTML 自适应屏幕宽度，移动端友好

## 🚀 快速开始

```bash

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

启动后访问 `http://localhost:5173` 即可使用。

## 📖 使用教程

### 1. 上传底图
- 点击「选择图片」上传本地图片
- 支持常见格式：JPG / PNG / GIF / WebP

### 2. 添加热区
- 点击工具栏「➕ 添加热区」按钮
- 在画布上拖动热区调整位置
- 拖拽四角控制点调整大小

### 3. 配置链接
- 在右侧热区列表中输入跳转链接
- 点击热区或列表项可切换选中状态

### 4. 多图管理
- 点击顶部标签栏「➕」新增图片
- 点击标签切换编辑不同图片
- 点击标签上的「×」删除图片

### 5. 导出成品
- 点击右上角「导出成品 HTML」
- 设置页面标题、图片模式、热区样式、布局方式
- 点击「导出下载」获取独立 HTML 文件

## 📦 导出成品说明

| 选项 | 说明 |
|------|------|
| 页面标题 | 成品 HTML 的 `<title>` |
| 外链图片 | 图片保持原 URL，文件体积小，需网络访问 |
| Base64 内嵌 | 图片转 base64 写入 HTML，完全离线可用，文件较大 |
| 隐藏边框 | 成品页中热区不可见（仅点击区域） |
| 显示边框 | 成品页中热区显示虚线边框（便于调试） |
| 垂直排列 | 多张图上下排列（适合长图/海报） |
| 水平排列 | 多张图左右排列（适合网格展示） |

## 📄 数据结构

```json
{
  "imgUrl": "https://.../banner.jpg",
  "imgWidth": 750,
  "imgHeight": 400,
  "areaList": [
    {
      "x": 50,
      "y": 50,
      "w": 200,
      "h": 80,
      "link": "https://example.com"
    }
  ]
}
```

- 所有坐标基于图片原始尺寸（设计稿尺寸）
- 成品页会按实际渲染宽度自动比例换算
